# ERP System Chatbot
 Bitn'Build 2024 IIIT Sri City

Our team, Algnite has developed a chatbot with RASA that integrates easily with the ERP website to give the user a way to ask their queries.
The chatbot is not rule based, which means it can grammatical errors and spelling mistakes, as demonstrated in the video.
The chatbot also allows the user to traverse the website using the chatbot, making it easier to navigate for the user. A chatbot like this in
a much larger website which presents a lot more data in often an unintuitive way can be very useful for the user.

<p>To try out the project,<br>
1)Create a new folder, open terminal in the folder's location <br>
2)Create a python virtual environment in the folder <br>
   In windows, use- i) python -m venv myenv <br>
                   ii) myenv\Scripts\activate <br>
   In Linux, use- i) python3 -m venv myenv <br>
                 ii) source myenv/bin/activate <br>
3)install RASA using- pip install RASA <br>
4)Create New folder in the folder where you set up Virtual Environment <br>
5)Open the new folder and unzip the download code from this repository there <br>
6)In terminal where virtual environment is running, change directory to the new folder where you unzipped the code <br>
7)In terminal type-> rasa run --cors "*" <br>
8)After RASA server is up and running, open the folder webpage from the downloaded code. <br>
9)There is a webpage.html file, run it on a web browser to see the project. <br>
